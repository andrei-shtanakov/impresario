# Реестр стандартов экосистемы

Входной артефакт для оси `fit_standards` (Stage 4 pilot). Выжимка
действующих правил экосистемы (SSOT — `prograph-vault/authored/rules/`
и CLAUDE.md репозиториев).

**Ref-грамматика:** `standards://ecosystem/<ID>` (например,
`standards://ecosystem/STD-2`).

## Процесс и governance

### STD-1. PR-only, мерж — человек

Изменения в репо с remote — только через PR; ревью отрабатывается; мержит
человек. Прямые коммиты в default-ветку запрещены (исключение — bootstrap).

### STD-2. Fail-closed с enforcement point

Заявленный инвариант обязан иметь класс enforcement
(`schema | tool | human/process | planned`). Зелёный гейт не доказательство,
пока fail-closed не покрывает сам прибор (оракул, exit-семантика,
provenance).

### STD-3. Вендоринг контрактов с двумя гарантиями

Кросс-репный контракт потребляется пинованной копией внутрь; у копии две
гарантии: copy-integrity (PR-гейт) и upstream-drift (scheduled watcher).

### STD-4. Immutable decision records + human authority

Authority-решения (гейты, waivers, мержи) — записи с actor identity,
версией предмета и причинами; исправление — новой записью, не правкой
старой.

### STD-5. Канон-first / SSOT

Канонические факты живут в репо-владельце. `_cowork_output/` — dev-only,
не SSOT и не runtime-зависимость.

## Данные и безопасность

### STD-6. Публичный контур без приватного контента

В публичных репо не появляются секреты, клиентские данные и приватные
методологии. Секреты — только env; KB и конфиги их не содержат.

### STD-7. Durable state — восстановимый

Состояние процессов crash-safe (класс решений: SQLite WAL,
validate-then-atomic-replace, монотонные версии, idempotency keys);
скрытый контекст чата состоянием не является.

## Инженерные стандарты (Python-линия)

### STD-8. Стек качества

uv (не pip), pytest (+anyio для async), ruff (88 колонок), pyrefly,
type hints, докстринги публичных API. Новые фичи — с тестами; багфиксы —
с регрессионными.

### STD-9. Наблюдаемость изменений

Новый репо/переименование регистрируется в обзорных поверхностях (зеркала
Robin, реестры) тем же изменением; «молча слеп» — дефект.
